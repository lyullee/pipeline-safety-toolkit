# Pipeline Safety Toolkit

Archived release: [Zenodo DOI 10.5281/zenodo.23899127](https://doi.org/10.5281/zenodo.23899127) · [GitHub Release](https://github.com/lyullee/pipeline-safety-toolkit/releases/tag/v0.1.0a1)
**Composable Python tools for pipeline engineering, model exchange and reproducible verification.**

배관의 유동·열역학·구조·손상·계측·운영 계산을 작은 모델과 명시적인 데이터 계약으로 연결하는 연구용 패키지입니다. 사용자 파라미터, 물성 공급자, 관측 데이터와 외부 엔진을 교체할 수 있습니다. 결과에는 단위, 적용 조건, 입력 출처와 실행 식별정보를 함께 남깁니다.

- **배포 이름:** `pipeline-safety-toolkit`
- **Python import:** `pipeline_integrity` — 기존 코드와의 연결을 위해 유지합니다.
- **공개 버전:** `0.1.0a1` — 연구용 알파 버전입니다.
- **Python:** 3.12 이상
- **라이선스:** MIT. 별도 라이브러리와 데이터의 이용조건은 각 출처에 따릅니다.

## 단위 모듈을 찾고 사용하는 순서

1. **계산 목적 선택:** 아래 분야 표에서 문제를 고른다. 간단한 단일 계산은 [25개 기본 계산 입출력](#바로-호출하는-기본-계산-모듈-25개), 전문 해석은 [223개 방법 표](#모델별-목적입력출력-223개)를 사용한다.
2. **입력 준비:** 파라미터 이름, SI 단위, 필수값과 선택값, 관측 위치·시계·압력 기준을 맞춘다. **request는 입력 구조체, context는 실행 문맥, provider/client는 교체 가능한 물성·외부 계산 엔진**이다.
3. **API 선택:** 레지스트리 계산은 `engine.evaluate()`로 호출하고, 전문 모델은 표에 연결한 Python 함수를 해당 request 타입으로 호출한다. 공학 방법 ID를 그대로 `engine.evaluate()`에 넣을 수 있는 것은 아니다.
4. **출력 확인:** 성공 상태와 결과 키·단위부터 확인한 뒤 다음 계산으로 넘긴다. 외부 엔진이 필요한 계산은 해당 엔진을 설치·주입해야 한다. `needs_data`/`out_of_scope`를 성공값이나 0으로 취급하지 않는다.

### 공통 입력과 출력의 의미

| 항목 | 사용자가 넣거나 읽는 내용 |
|---|---|
| `request` 또는 `p` | 해당 모델의 입력 구조체. 필수값·허용 선택지·기본값은 [API 상세](docs/MODULE_IO_REFERENCE_KO.md)에 표시한다. |
| `RunContext.asset_id`, `scenario_id`, `clock_id`, `origin` | 각각 설비, 시나리오, 시간축, 관측/실험/시뮬레이션/사용자 선언 등의 입력 성격. 네 항목이 필수다. |
| `RunContext.evidence`, `metadata` | 선택 근거와 부가 정보. 특정 모델이 근거 ID를 요구하면 evidence에도 그 실제 기록을 넣어야 한다. |
| `*_basis_id`, `*_evidence_id`, `*_reviewed` | 단위·상관식·경계·재료의 적용 근거와 검토 여부. 단순한 주석이 아니라 일부 계산을 보류시키는 입력이다. |
| `provider`, `client` | 물성·분산·외부 재료/위험 엔진 등. `None`이 허용되는 경우에도 해당 계산 경로는 실제 구현을 요구할 수 있다. |
| 레지스트리 `AssessmentResult` | `status`, `inputs`, `values`, `input_units`, `output_units`, `notes`, `context`, `input_digest`, `model_source_digest`, `runtime` 등을 가진다. |
| 직접 API의 결과 | `Calculation`, typed 결과 구조체, dict, tuple 또는 float 등 API마다 다르다. 모든 반환값을 `AssessmentResult`로 가정하지 않는다. |

`parameters`·`values`가 외부 엔진의 모델별 dict인 경우 내부 키는 선택한 owner 모델의 schema에 따른다. 이 패키지의 교환 계약이 그 엔진의 모든 물리 파라미터를 대신 정의하지는 않는다. 검토 근거 없이 `*_reviewed=True`로만 바꿔 계산을 통과시키지 않는다.

주요 단위는 압력 `[Pa]`, 길이 `[m]`, 시간 `[s]`, 절대온도 `[K]`, 체적유량 `[m³/s]`, 질량유량 `[kg/s]`, 밀도 `[kg/m³]`, 점도 `[Pa·s]`, 동점도 `[m²/s]`, 힘 `[N]`, 모멘트 `[N·m]`, 동력 `[W]`, 에너지 `[J]`다. 압력은 absolute/gauge/differential 기준을 따로 확인한다. 표준 체적의 기준 상태와 경험계수의 단위는 별도 입력이며 자동으로 결정하지 않는다.

```python
for name, parameter in schema["properties"].items():
    unit = description["model"]["input_units"][name]
    print(name, unit, "필수" if name in required else "선택", parameter)
print("출력:", description["model"]["output_units"])
```

위 펌프 예시의 필수 입력은 `volume_flow_m3_s`, `density_kg_m3`, `head_m`, `pump_efficiency`, `motor_efficiency`입니다. `gravity_m_s2`의 기본값은 **9.80665 m/s²**이며 효율은 **0보다 크고 1 이하인 비율**입니다. 출력은 `hydraulic_power_w`, `shaft_power_w`, `electrical_power_w`이고 단위는 모두 **W**입니다. 이 구분을 다른 API에 그대로 적용하지 말고 해당 API 명세를 확인하십시오.

전문 모델의 직접 호출에서도 입력 구조체의 schema를 조회할 수 있습니다.

```python
from pipeline_integrity.models.hydraulics import LiquidHeadLoss

print(LiquidHeadLoss.model_json_schema())
# diameter_m, length_m, roughness_m, volume_flow_m3_s,
# kinematic_viscosity_m2_s는 필수.
# minor_loss_coefficient, outlet_minus_inlet_elevation_m,
# gravity_m_s2, transition_policy, friction_method는 기본값을 갖는다.
```

한 방법에 API가 여러 개이면 필요한 API를 명시적으로 선택하십시오. 반환된 callable은 원래 함수입니다. 각 함수의 request, context, provider와 결과 형식을 하나의 범용 딕셔너리로 강제 변환하지 않습니다. [카탈로그](docs/MODEL_CATALOG_KO.md)에 허용된 연결점과 실제 소스 경로가 정리되어 있습니다.

## 사용자 데이터와 모델을 연결하는 원칙

1. **단위:** 모델 경계는 SI를 사용합니다. 기준 상태가 있는 표준 체적, gauge/absolute 압력과 온도 기준은 별도로 명시합니다.
2. **문맥:** 설비·위치·시계·관측 출처·물성 기준이 다른 기록을 조용히 합치지 않습니다.
3. **물성:** 물성 공급자를 주입할 수 있습니다. 요청한 유체·상태·버전과 반환값을 확인합니다.
4. **자료:** reader는 원 자료의 결측·부호·시각과 식별정보를 보존합니다. dataset 등록이 다운로드나 실측 적합성 통과를 의미하지 않습니다.
5. **교정:** 학습 자료와 비교 자료를 나누고, 실제 물성으로 식별한 값과 손실을 흡수하는 유효 계수를 구분합니다.
6. **위험 연결:** 수명, 손상, 요구 시 실패확률, 기간확률, 빈도와 위험 점수의 의미를 따로 지정합니다. 임의의 한 값으로 치환하지 않습니다.
