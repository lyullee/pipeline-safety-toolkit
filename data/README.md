# Local research data

This directory is reserved for separately acquired raw data, reference observations,
and locally transformed records. Its contents are not published with the code.
Only this guide and the exclusion rules are Git-visible.

Use the source catalog, source-specific acquisition scripts and rights/checksum
records described under `docs/` to acquire data. Preserve the source license,
citation, units and provenance. A public source license is not a statement that
its observations match a model's supported conditions.

The portable public test subset uses authored synthetic cases. Full research
campaigns additionally require the declared observations, external engine versions
and reference fixtures; see `docs/RELEASE_VERIFICATION_KO.md`.
