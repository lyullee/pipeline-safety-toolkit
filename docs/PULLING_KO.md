# 주어진 경로의 유연선 인입 계산

구현 범위는 검토자가 지정한 매끄러운 안내 경로를 따라 움직이는 유연선의 준정적 인입이다. 직선과 원호를 연결하여 3차원 경로를 구성한다. 관의 유한 굽힘 강성, 지반 반력, 접촉 위치, 좌굴 및 시공 중 동역학을 풀지 않는다. 따라서 `construction.pull` 전체 기능은 부분 구현 상태이며 실제 관 인입 설계를 이 결과만으로 승인할 수 없다.

## API와 입력 책임

`pipeline_integrity.pulling`의 `PullingSegment`, `PullingLimits`, `PullingRequest`, `evaluate_pulling`, `verify_pulling_record`를 사용한다. 기존 `RunContext`로 자산, 시계, 시간, 좌표계, 양단 포트 및 근거를 결합한다. `examples/pulling.py`의 `make_case()`는 합성 사례의 요청과 문맥을 생성한다. 검토 플래그의 기본값은 거짓이며 기본 사례는 `needs_data`를 반환한다. `make_case(reviewed=True)`는 설명용 가정에 대한 검토를 표시하는 예일 뿐 현장 검토의 대체물이 아니다.

사용자는 선 질량, 내부 내용물 질량, 배제 면적, 유체 밀도, 침수 비율, 미끄럼 마찰계수, 추가 축방향 저항 및 후단 장력을 공급한다. 허용 장력, 최소 반경, 허용 기하학적 변형률도 적용 조건과 근거를 붙여 외부에서 공급한다. 규격이나 제조사의 수치를 기본 내장하지 않는다. 외부 모듈은 이 입력 계약을 생성하는 어댑터로 연계할 수 있다. 현재 API는 임의 함수 콜백이나 공간 가변 물성 공급자를 지원하지 않으며 구간별 상수로 분할해야 한다.

길이는 m, 질량 선밀도는 kg/m, 힘은 N, 선하중은 N/m, 밀도는 kg/m³, 속도는 m/s, 동력은 W이다. 경로 좌표 `s`는 후단에서 인입기로 증가한다. 중력 벡터도 같은 좌표계로 제공한다. 인접 구간의 위치와 접선은 선언된 허용오차 안에서 연결되어야 한다. 코드가 꺾임이나 불일치를 자동 보정하지 않는다. 각 원호는 반 회전 이하이며 단위 접선과 곡률 법선을 명시한다.

## 힘 모델과 수지

유효 질량 선밀도는 `m = m_pipe + m_contents - immersion * rho_external * area_displaced`이고 체적력 선밀도는 `w = m * gravity`이다. 부력이 더 크면 음의 유효 질량을 유지한다. 접선 `t`, 곡률 벡터 `kappa`, 유효 축장력 `T`에 대해 안내면의 반력 크기는 `N = norm(T*kappa + w - dot(w,t)*t)`로 평가한다. 축방향 방정식은 `dT/ds = mu*N + drag - dot(w,t)`이다. 완전한 안내 접촉과 지속적인 정방향 미끄럼은 별도 검토 가정이다. 이 식이 자유로운 접촉 형상이나 실제 토압을 결정하지 않는다.

기존 SciPy `solve_ivp`의 DOP853을 사용하며 별도 적분기를 만들지 않았다. 마찰, 추가 저항, 체적력의 축방향 성분도 함께 적분한다. 체적력 적분은 구간 양단 높이 차이에 해당하는 벡터 내적으로, 추가 저항은 구간 길이의 곱으로 독립 대조한다. 잔차와 입력 수치 허용오차를 보존한다. 속도가 있으면 후단/인입기 동력과 각 저항의 동력 수지를 산출한다. 이는 W 단위의 정상 동력 수지이며 시간 적분된 J 단위 작업량은 아니다.

장력이 0 이하가 되거나 수치 상한에 도달하면 양의 장력 모델 범위를 벗어난 것으로 처리한다. 값을 잘라서 정상 결과로 반환하지 않는다. 적분 실패, 평가 횟수 초과, 비유한 값 및 수지 불일치도 `out_of_scope`로 분류한다. 최대 적분 간격, 평가 횟수 및 장력 상한은 요청에 보존한다.

## 경계 판정의 의미

출력에는 표본 장력 최대값과 별도의 전체 경로 상한이 있다. 직선의 상수 기울기는 직접 상한을 구한다. 원호는 미분 부등식의 보수적인 지수 상한을 전파한다. 이는 연속 유연선 모델의 수학적 포락이며 부동소수점 구간 연산으로 인증된 오차 경계는 아니다.

- 표본값이 공급 한계를 넘으면 `exceeds_supplied_limit`이다.
- 전체 상한이 한계 이하일 때만 `within_model_upper_bound`이다.
- 표본은 낮지만 상한이 높거나 표현 불가능하면 `indeterminate_conservative_enclosure`이다. 이를 실제 과부하로 단정하거나 전체 경로 통과로 표시하지 않는다.

외경/(2×반경)은 기하학적 외측 섬유 변형률 지표이다. 응력, 소성, 단면 변형이나 좌굴 판정이 아니다. `computed_diagnostic`도 안전 승인이라는 뜻이 아니며 개별 한계 초과 여부를 반드시 읽어야 한다. 입력 또는 검토 근거가 없으면 `needs_data`이다. 힘 계산 후 허용치나 필수 속도만 부족한 경우 힘은 유지하고 미완료 항목을 표시한다. 필수 동력 검토를 끄는 선택은 요청에 명시한다.

## 재현과 변경 추적

기록은 전체 요청/문맥, 형상 다이제스트, 소스 해시, Python 및 수치 라이브러리 버전, SciPy 적분기와 계수 소스 해시를 보존한다. `verify_pulling_record(record, request=..., context=...)`는 현재 환경에서 다시 계산하여 요청과 결과를 비교한다. 무서명 해시이므로 과거 실행의 신원이나 위조 방지를 보장하지 않는다. 버전이 달라진 환경에서는 별도 검토와 재계산이 필요하다.

## 현재 검증 상태와 다음 실행

구현 및 의미 있는 회귀 시험 코드를 작성했다. 사용자 지시에 따라 이번 작업에서는 Ruff와 Python 컴파일만 수행하며 pytest, 수치 예제 및 벤치마크 실행은 누리온 단계로 미룬다. 따라서 회귀 시험 통과 또는 현장 검증 완료를 주장하지 않는다. 시험에는 직선 마찰, 경사 중력 부호, 무게 없는 원호의 지수 장력, 중립/초과 부력, 독립 저항 수지, 불명 입력, 연결 불량, 모델 범위 이탈 및 기록 변조가 포함된다.

후속 환경에서 실행할 명령: `python -m pytest tests/test_pulling.py -q`. 이 명령과 예제 실행 결과를 실제 환경/의존성 버전 및 실패 기록과 함께 보존한 뒤 검증 상태를 갱신한다. 합성 입력은 공개 공정 데이터나 현장 성능 검증을 대체하지 않는다.

## 확장 요청 초안: PI-X04/01

다른 구조/물성 모듈 담당 세션에 다음 입력과 출력 계약의 확장을 요청한다. 기존 재료 모델을 재사용하는 EA/EI 및 온도 의존성, 접촉 활성 집합과 안내 반력 방향, 토질/공벽 상호작용, 유체 유변학 기반 저항, 채움/부력 조건, 압력과 잔류 변형, 국부 및 전체 좌굴, 속도 변화에 따른 관성 효과가 필요하다. 경로와 접촉을 미지수로 풀 때는 경계 조건, 좌표계, 양단 포트, 에너지와 힘 수지, 수렴 실패 및 적용 범위를 함께 반환해야 한다. 라이선스가 확인된 실제 입력과 독립 검증 사례도 필요하다. 현재 유연선 계산을 유한 강성 관 해석으로 재명명해서 완료 처리하지 않는다.
