# 후속 연구와 구현 우선순위

현재 기술 목록은 201개이며 이것이 201개의 수치 모델 완성을 뜻하지 않는다.
16개 계획 항목과 부분 구현 21개·현장 절차 공급 29개는 계속 남는다. 새 연구자는
`pipeline-integrity capabilities`에서 ID·소유자·상태·다음 작업을 확인한다.

## 우선순위 1: 실제 자료와 물리 경계

1. 반복 ILI의 검사 위치·오차·결함 정합을 기존 재료 프로젝트와 구현한다.
2. 명목 관망과 SCADA의 차이를 포함한 보정·시간순 검증을 진행한다.
3. 실험 누설 자료를 파일별로 확보하고 단위·샘플링·실험 분할을 확인한다.
4. 방출 엔진에 시계·포트·밸브 운동·잔류 재고 경계를 연결한다.
5. 수송·감지·HRA·결과의 근거 ID와 조건부 사건을 위험 엔진으로 보존한다.

새 자료를 많이 받는 것보다 동일 원본·권리·생성 방식·적용 한계를 확정하는
것을 우선한다. 수소·천연가스·물 실험은 서로 직접적인 성능 검증 자료가 아니다.

## 기간 위험과 크리프 수명의 다음 구현

CREEP_KO의 원7모델과 검열 수명/기간 사건 바인딩을 재현한다. 기존 HRA Boolean
엔진을 재사용하는 공통 기간 어댑터는 PERIOD_RISK_KO에 구현했다. 정확한 기간·생존 조건·
물리 endpoint·원 모델/방호 계보·공유 의존 그룹과 공동 상태를 보존하고 demand
전용 FTA 및 연간 환산의 계약은 유지한다. 관측 공동 의존성과 모수 불확실성,
시간 순서·수리·원 물리 사고 결과를 후속 구현한다. 여러 시점의 사건을
정적 Boolean 계산에 넣어 연속시간 고장과 복구를 검증했다고 주장하지 않는다.

원 Mat 확장은 PI-X04의 시편 단위 모수 불확실성·지원·다온도·변동 조건·제어
기준·크리프–피로를 따른다. 한 온도의 CMSX-6를 강관/현장 자료로 전이하지 않는다.

## 우선순위 2: 고급 수송·과도 모델

방출부터 실제 PRISM·SLABx 조건부 결과와 연간 환산까지의 선택 경계는 확인했다.
횡풍·비스듬한 평면의 실패를 PI-X03으로 넘기고, 전체 사건 종료·구름 꼬리·
기상·빈도·노출 자료와 독립 실험 비교를 남긴다. 현재 수치는 유한 시간창의
진단·미계산 범위이며 전체 위험을 완성한 것으로 집계하지 않는다.

물의 반사파·밸브·펌프 과도에는 [TSNet](https://github.com/glorialulu/TSNet)을
후보로 조사하고 0.3.1을 NumPy 2.5.4/WNTR 1.5에서 실행했다. 격자 생성의
배열→정수 변환에서 실패해 채택하지 않았다. 소스를 복제·변형하는 대신
단상 액체 특성선법을 독립 구현하고 기준 파·분기·격자·보존량을 확인했다.
기존 유한 스트로크 구동기를 액체 밸브의 압력 의존 유량에 연결하고 지연·
역류·병렬·닫힘 누설·관별 수지를 확인했다. 펌프 관성·기체 잔류·다상은
미완료이며 이 합성 액체 기준을 실제 차단 성능 검증으로 확대하지 않는다.

가스 비등온 과도, 파단 양방향 방출, 잔류 방출 연성, 2상·액주 분리, 슬러리,
비뉴턴 유체, 다품종 이송·피그 운동·수화물·가열 원유는 계획 상태다. 기존
물리 엔진의 확장 가능성을 조사한 뒤 새 구현의 필요성을 판단한다. 단순
수격 규모식이나 일반 콜백을 완전한 과도 해석기로 표시하지 않는다.

단일 출구 유한 배관 사고 이력은 부분 구현으로 전환했다. 일반 수소 기체의
원본 계산·질량 장부·PRISM 전달을 확인했고, 파라수소 표시·2상 기체 밀도·액체
도달 좌표의 원본 불일치를 보류했다. PI-X01 수정과 에너지 원장·공유 재고·
양방향 경계·차단 후 재고 방출 검증이 남는다. 다른 계획 항목은 계속 유지한다.

## 우선순위 3: 감지·검사·설계 최적화

선형 지지/분기 프레임은 PyNite 3.2.0으로 부분 구현했다. STRUCTURAL_KO의
3D·스프링·지점 이동·회전 해제·독립 수지·소변위 보류를 재현한다. 원 시험
하중32개를 가정한 축 프레임에 대입한 결과는 실제 치구 검증이 아니다.
균일 열과 독립 직선 관의 pressure cap+Poisson·실제 축력 복원은 FRAME_LOADING으로
추가했다. 20사례·원 온도차16snapshot을 확인했고 실제 봉재 응력 검증은 남는다.
비균일 온도·초기 곡률·분기 압력 경로·엘보/티 유연성·국소 응력 복원·
지반/간극/마찰·P-Δ/좌굴·독립 시험으로 확대한다. 구조 엔진을 새로 복제하지 않는다.

반복 ILI의 단위 판독·좌표 등록·일대일 위치 후보·미대응·국소 모호성과 검토
경로의 Mat 추세 연결은 부분 구현했다. 실제 정합 정답·시각·계측 오차가 없어
현장 성장 검증은 남는다. 분할/병합·POD·좌표 교정·계측 편향과 최대 깊이의
이동을 후속 전문 모델로 확장한다. 위치 비용을 대응 확률로 사용하지 않는다.

강건 통계·PCA를 비교 기준으로 유지하고 동적 부분공간·예측 잔차·행렬 프로파일·
그래프·딥러닝 등 기존 모니터링의 후보를 동일 분할에서 비교한다. 유행이나
발표 연도만으로 우선하지 않는다. 물리 잔차가 제공하는 개선, 자료량, 계산량,
조건 변화, 오경보·누설 지연을 함께 평가한다.

센서 위치·검사 주기·관경·펌프 운전·투자·정비 자원 최적화는 검증한 전방
모델과 실제 제약을 먼저 마련해야 한다. 지지·좌굴·지반 연성·탱크 동역학 연계·공사 경로·
인양·특수 횡단은 적용 자료와 공급자/현장 기준이 확보된 항목부터 진행한다.

## 기술 전체를 모듈화하는 방식

economics.lifecycle의 명시한 비용/CO2e 재고·가격 기준·지급/반복 시각·기준 대안
비교와 전력/일정/위험 연결을 구현했다. LIFECYCLE_KO를 재현한 뒤 실제 요금·
수명·운전/작업·손실 자료와 공동 불확실성으로 확대한다. 선언한 입력의 비교는
경제적 최적 정비 주기·수송/설계 최적화나 실제 현장 경제성 실증을 대신하지 않는다.

계산 가능한 항목은 입력·출력·가정·기준 문제를 갖춘 모델로 만든다. 기존
프로젝트가 가진 항목은 어댑터와 소유 책임으로 연결한다. 자격·공법·현장
판단이 필요한 기술은 기준 공급자와 근거 절차로 표현한다. 아직 계산 또는
검증할 수 없는 항목은 계획 상태로 유지한다. 이 구분을 유지하면서 목록의
범위를 넓혀 중복 구현과 완료 상태의 과장을 줄인다.

## 성분 수송 후속 범위

`transport.batch_interface`는 물의 희석 수송 기반을 근거로 partial로 변경했다.
다품종 제품의 열·밀도·점도 피드백과 축방향 분산·다성분 반응·실제 품질 관측
비교는 남는다. `WATER_QUALITY_KO.md`의 기준 문제와 보류 기록을 먼저 확인한다.
L-TOWN의 기존 strict 수력 설정은 반복 초과 경고가 있어 수지 통과만으로
승인하지 않는다. 원본 운전/장치 조건과 수렴을 함께 검토하고, 합리적 기준
변경이 필요하면 그 근거와 전후 비교를 별도 연구로 남긴다.

## 물리 모델 보정의 명시적 범위

기존 명목 관망 보정 과제를 `network.calibration` ID로 추가한다. 관측·예측의
자산·시계·단위와 시간 분리, 파라미터 경계, 잔차 척도, 모델 호출 예산, 국소
식별성을 먼저 정의한다. 합성 정답과 공개 SCADA의 전후 오차를 따로 확인한다.
이는 누설 위치 정답·독립 현장 검증 또는 전체 공동 불확실성 추정의 완료가 아니다.

## 음향 후속 범위

음향은 동시 파형·시계 보정·상관/PHAT·조건부 구간 위치와 오차 경계까지
부분 구현했다. 실제 파속·분산·상대 시계·센서 오프셋·반사·분기 근거와
독립 위치 오차 평가가 남는다. 정답이 없는 상관 정책 통과 수만으로 새
방법을 우선하지 않는다. 같은 기록의 인접 창을 독립 검증으로 사용하지 않는다.

## 일반 기체 관망의 현재 연결

일반 기체 관망은 planned에서 partial로 전환했다. 원 P/h·분할 관·기체 물성을
재사용했고 인출·열·혼합·역류·병렬·정체를 확인했다. GAS_NETWORK의 실제 수지와
수치 기준을 재현한 뒤 PI-X01의 전체 에너지·고도·노드 부하·잔차 스케일·능동
장치를 확장한다. 원 GasLib 전체 운전을 단일 형상의 별도 메탄 사례와
구분한다. 비정상·상변화·누설·독립 실험은 계속 남아 있다.

## 선언한 자원 일정의 구현

operations.scheduler의 유한 격자·필수/대체 방식·자원/교대·hold·소모품·시간
관계·선언 목적과 독립 감사는 구현했다. 원 HRA Task 연결은 실제 확인했다.
입력 근거와 모델의 최적성을 현장 작업 자격·실행 가능성·인적오류 감소로
확대하지 않는다. 불확실 시간·실시간 변경·실제 완료·위험 연계와 PI-X06의

## 인적 반응 경계 이후

HUMAN_RESPONSE_KO의 현재 원 엔진 연결을 재사용한다. 확률적인 공정 기한과

## 관측 적합 이후의 우선순위

수정하면 새 평가 자료를 확보한다. 원 그룹이 분리된 운전/실험, 시간·모드별
모형과 모수/모델 형식 오차·검열/결측 기전·꼬리/공통원인·전체 위험 연성으로
확대한다. 전체 정상/안정10행의 부족을 다른 고장 프로필을 섞어 메우지 않는다.

## 재료 품질·수소 수송·감육 용량과 신뢰도 대조

## 감시·설비·풀·지식·토양 경계 이후의 전체 범위

모니터링의 dynamic_pca와 neural/temporal_neural을 실제59개/7family 경계에 추가했다.
