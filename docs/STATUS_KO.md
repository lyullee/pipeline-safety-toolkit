## 공동 잔차·원자료 전송의 추가 개발

운전점 역추정과 관 마찰 study에 명시한 공동 covariance/scaling 행렬을 연결하는
코드를 작성했다. 행 ID·단위·순서·원본 SHA와 검토 근거를 보존하고, 훈련과 heldout은
각 valid principal block으로만 계산한다. scalar 척도를 중복 적용하거나 미상 상관을
0으로 채우지 않는다. 회귀는 누리온 대기이고 확정 진행률은 67.2%를 유지한다.

압력 CSV prefix 도구는 실패·timeout·불완전 행과 정상 제한 읽기를 구분하고
기존 output 덮어쓰기를 거부하도록 보강했다. 새 원자료 추출은 실행하지 않았다.
원자료 전송 확인 도구는 관 마찰 4파일·12,340바이트에서 실제 해시 일치를 확인했다.
이 확인은 모델 시험·자료 의미 검증·전체 fixture 준비 완료를 뜻하지 않는다.
새 공동 잔차 코드와 전송 도구의 수치·회귀 시험 통과 주장은 없다.
이번 baseline 대비 새 회귀 함수 35개는 미실행이다. 전체 src/scripts/tests/examples의
Ruff·format check·compileall은 통과했다. 상세는 `research/joint_metric_transfer_status.json`,
전송은 source-only batch10과 대응 8분할 manifest를 사용한다.

관 마찰 원자료를 실제 소비하는 시험 모듈을 rank 하나에 연결하는 fixture 배치 계약을
추가했다. 원본과 격리 복사본을 시험 전후 SHA로 다시 검사하며 경로는 manifest에 넣지
않는다. 12,340바이트 staging은 형식·무결성 검사까지 수행했다. MPI/PBS/pytest는
실행하지 않았으며 최신 plan/bundle은 batch14로 갱신한다.

공개 자료 논문에서 동압 센서 PCB 102B16, NI-9234, 51.2kHz, 센서 감도와 범위를
확인해 별도 metadata API에 기록했다. CSV `Sample`/`Value` 변환과 P1/P2 trigger는
여전히 미확인이며 출판 주파수를 parser 기본값으로 적용하지 않는다. 이 변경 이후
누리온 manifest와 source bundle은 batch14로 함께 동결한다.

같은 파일명 조건의 P1/P2에서 각각8개 완성 행을 제한적으로 실제 읽고 receipt 내부
일관성을 확인했다. 헤더와7개 좌표 prefix는 같고 값 prefix는 다르지만, 이 관계는

후속 소비자가 파일명/같은 좌표를 동기화 증거로 오용하지 않도록 공개

clock ID나 SI 좌표가 다르면 거부하며, pairing은 도착/누출발생 정답이나 단위 검증을
만들지 않는다. 새 계약 회귀4개는 누리온 대기라 진행률은67.2% 그대로다.

trace pair를 NPW request/context에 결합하는 바인더도 추가했다. P1/P2의 좌우 역할을

count 영수증의 원표 재생 verifier와 FTA `joint_state_receipt_digest` 계보를 추가했다.
공통원인 모수/불확실성·검열/노출·시간순서/수리는 복제하지 않고 현재 consumer source
SHA를 고정한 `PIPE-EXT-011`로 HRA 소유 저장소에 요청했다. 외부 구현은 미확인이다.

다품종 액체 배치 수송의 owner-provider 경계를 새로 작성했다. 조성 closure, 시간–위치

성분 합–총량 일치도 요구해 성분 손실/생성 상쇄를 막았다. 새 함수5개·매개화5사례는 누리온 대기이며

실제 80/80/122 재고 소비 시험을 연결했다. 절대 raw 경로는 manifest/receipt에 남지 않는다.
controller/통합 회귀 각1개는 작성만 했고 MPI/PBS/pytest는 미실행이다.

없다. 누수 archive는 1-rank targeted 캠페인, 관마찰은 기존 full-suite 캠페인으로 각각
실행·집계한다. controller 회귀1개를 추가했으며 아직 실행 전이다.
targeted archive 캠페인이 private map 없이 무자료 통과하지 못하도록 campaign kind를 자식

원자 설치 후 읽기 전용으로 봉인한다. 원 업로드 파일과 절대경로는 receipt에 남기지 않는다.
정식 상대경로로 이미 전송한 파일을 복사 없이 봉인하는 `--verify-existing`도 추가했다.

가속도 A1/A2 CSV를 기존 음향 엔진의 `SampledTrace`로 옮기는 자격·재생 브리지를 추가했다.
