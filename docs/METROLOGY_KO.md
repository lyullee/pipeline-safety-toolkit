# 계량 불확실도와 선언 판정

`pipeline_integrity.metrology`는 명시한 입력 추정값, 표준 공분산, 해당 입력에서
평가한 측정 모델의 민감도를 결합한다. 측정 모델을 적합하거나 누락된 상관관계를
추정하지 않는다. 원래 모델·교정 절차와 판단 책임을 보존하면서 계량 결과를 다른
공정·위험성 평가 모듈에 전달하기 위한 공통 경계다.

## 수학과 입력 의미

입력 벡터를 x, 출력 벡터를 f(x), 표준 공분산을 U, 민감도 행렬을 J라 하면
국소 일차 근사의 출력 공분산은 J U Jᵀ이다. 출력마다 대각 기여와 입력 쌍의
공분산 기여를 따로 남긴다. 상관 기여는 음수일 수도 있다. 이를 절댓값으로
바꾸거나 독립적인 오차의 제곱합으로 대체하지 않는다.

이 수학은 [NIST의 불확실도 전파 설명](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-appendix-law-propagation-uncertainty)에
있는 일차 민감도·공분산 관계를 벡터 출력으로 적용한 것이다. 설명과 코드는
직접 작성했다. 표준 전문, 기관의 교정 절차 또는 산업별 허용 오차표를 포함하지 않는다.

입력은 모두 일관된 SI 단위다. `kg/s`, `m^3/s`, `K`, `Pa`, `1` 등을 사용하고
`kg/h`, `bar`, `degC`, `percent`는 이전 단계에서 명시적으로 변환한다. 압력 차원은
absolute/gauge/differential 의미를 선언한다. 단위를 SI로 바꾸어도 압력 기준과
유체 조성, 습분, 기준 체적의 상태가 자동 변환되는 것은 아니다.

- `MeasurementInput`: 식별자·추정값·물리량/단위/정의/근거와 `valid` 품질 선언.
  미상 값·품질은 `None`, 명시한 invalid는 `False`다. invalid 원값을 보존하고
  계산은 `out_of_scope`로 거부한다. 미상 품질은 `needs_data`이며 valid인데 값이 없으면 입력 오류다.
- `MeasurementBasis`: 물리량과 정의 식별자를 보존한다. 기준 체적에는
  `MeasurementReferenceState`로 절대 압력·온도·조성 식별자·습분 기준을 붙일 수 있다.
- `StandardCovariance`: 정확한 입력 순서, SI 단위 곱으로 표현한 모든 성분, 근거와 검토 여부.
  확대 불확실도를 직접 넣거나 표준 편차를 대각 성분에 넣지 않는다. 대각은 분산이다.
- `MeasurementLinearization`: 출력 추정값과 기반, 입력 해시, 모델/버전/소스/구성 해시,
  출력 순서의 행·입력 순서의 열로 된 Jacobian. 각 성분의 단위는 출력 단위/입력 단위다.
  입력 추정값·단위·물리적 기반이 달라지면 입력 해시도 바뀌므로 이전 민감도를 재사용할 수 없다.
- `MeasurementBudgetRequest`: 자산·시계·사건·시각과 위 계약을 묶는다.
  정적 사건 예산의 관측 시각이 없으면 `time_s=None`으로 보존할 수 있다.
  정적 공분산 계산에 가짜 시각을 만들지 않으며 시계열 신호의 시점으로 사용하지 않는다.

모델의 출력 값·미분이 물리적으로 맞는지는 모델 제공자의 검증 책임이다.
`local_approximation_reviewed=True`는 근거가 있는 호출자 검토 선언이다. 입력 범위를
크게 벗어나는 비선형 모델, 상변화 또는 밸브 개폐 같은 불연속 모델에 일차 근사를
자동 적용하지 않는다. 모델의 고유 실행 기록도 별도로 검증한다.

## 호출과 판정

실행 가능한 [예제](../examples/metrology.py)는 기준 유량 10 kg/s와 지시 유량
11 kg/s의 상대 오차 `I/R - 1`을 계산한다. 예제의 공분산은 직접 만든 수치이며
실측 교정 성적서로 해석할 수 없다.

```python
from pipeline_integrity.metrology import (
    propagate_measurement_uncertainty,
    verify_measurement_uncertainty,
)

record = propagate_measurement_uncertainty(request, context)
verify_measurement_uncertainty(record)
```

공분산이 미상인 성분을 하나라도 포함하면 전체 예산을 `needs_data`로 보류한다.
주어진 전체 행렬은 대칭·분산 비음수·양의 준정부호 성질을 검사한다. 단위 크기
차이에 지배되지 않도록 비영 분산 성분을 상관행렬로 정규화해 고유값을 검사한다.
행렬은 수리하지 않는다. 부동소수점 판별 공차와 실제 최소 고유값을 남긴다.
분산이 0인 입력은 명시된 확정값이며 미상 값과 다르다. 비정상 행렬과 표현 범위를
벗어나는 계산은 `out_of_scope`다. 음의 출력 분산을 0으로 잘라 숨기지 않는다.

`CoverageDeclaration`에는 호출자가 검토한 양의 계수 k를 넣는다. 확대 불확실도는
k u로 계산하지만 k=2를 넣었다는 이유만으로 95%를 계산했다고 표시하지 않는다.
확률을 별도로 제공하려면 그 근거도 함께 제공한다. 자유도나 정규분포를 자동 가정하지 않는다.
검토하지 않은 확대 선언은 사용하지 않으며 표준 불확실도 결과는 보존한다.

`MeasurementDecisionRule`은 출력 식별자·상하한·동일 출력 단위의 guard band·비교 방법·
근거를 명시한다. 명목값 비교 또는 확대 구간 비교를 호출자가 선택한다.
하한에는 guard band를 더하고 상한에서는 뺀다. 경계는 포함한다. 확대 구간 전체가
허용 구간 안에 있으면 `accepted_by_declared_rule`, 완전히 밖이면
`rejected_by_declared_rule`, 경계와 겹치거나 검토가 부족하면 `indeterminate`다.
검토한 확대 계수가 없으면 확대 구간 판정도 보류한다.

이는 선언한 규칙의 계산 결과이며 거래 계량 인증·법적 적합성·교정 인정 결과가 아니다.
모든 기록에 `custody_transfer_certified=False`와 `calibration_fit_performed=False`를 남긴다.

## 다른 모듈과 연결

[가스 유량계](GAS_METER_KO.md)의 질량 유량과 실제/기준 체적 유량은 서로 다른 물리량이다.
압력·온도·유체 조성·기하·Cd·팽창 계수의 오차를 전파하려면 실제 선택한 모델의 출력과
민감도를 받아 각각의 기반을 선언한다. 다른 온도·습분 기준을 가진 결과끼리 같은
식별자로 합치지 않는다. 이 서비스는 유량계 계수·물성·민감도를 임의로 만들지 않는다.

반복 자료에서 분포를 추정할 때는 기존 `uncertainty_fit`의 학습/평가 분리를 사용한다.
비선형 모델의 수치 전파는 기존 `uncertainty.generate_ensemble`과 `evaluate_ensemble`에
동일한 물리 모델을 연결한다. 입력 공분산만으로 유일한 공동분포를 얻을 수 없으므로
별도 분포·의존성·근거를 정한 뒤 사용한다. draw 식별자를 관측 시각으로 바꾸지 않는다.
교정 계수의 적합이 필요하면 기존 `inverse.fit_parameters`의 실제 모델·학습/검증 계약을
충족해야 한다. 이 모듈은 새 최적화기나 별도 난수 발생기를 만들지 않는다.

[공개 계량 자료](METER_DATA_KO.md)의 확대 불확실도와 반복 평균 오차는 출처의 의미를
유지한다. 그 자료에 구성 성분 간 공분산이 없다면 임의의 독립성을 넣어 전체 예산을
완성하지 않는다. 자료의 교정 성적과 현재 모듈에 대한 독립 현장 검증도 구분한다.

## 기록 검증과 현재 한계

`verify_measurement_uncertainty`는 요청과 문맥을 재검사하고 전체 공분산 전파와 판정을
다시 계산한다. 해시만 다시 붙인 출력·확대 불확실도·공분산·판정 변경도 거부한다.
현재 소스와 Python/NumPy 실행 버전이 같은 기록을 재구성한다. 기록의 입력이나 근거
자체를 다른 값으로 모두 바꾼 뒤 재발행한 사람의 진실성을 인증하는 기능은 아니다.

`python scripts/check_metrology.py`는 6개 원작성 기준과 4개 재봉인 변조 거부를
요약한다. [64개 검사](../tests/test_metrology.py)는 완전 양·음 상관, 특이 공분산,
다중 출력, 미상/부적합 공분산, 상태 결속, 단위, 확대와 경계 판정 등을 확인한다.
[집계 기록](../research/metrology_results.json)에는 원시 관측을 넣지 않는다.

독립 검토에서 `model_copy`로 검증을 우회한 NaN 공분산·무한대 metadata가 JSON
직렬화 중 `null`로 바뀌던 경로를 재현했다. 현재는 Python 값으로 요청과 문맥을
먼저 엄격히 재검사한다. 복제한 공분산/입력/출력·metadata의 NaN/무한대 5사례를
입력 오류로 거부하며 결측 보류나 정상 계산으로 바꾸지 않는다.
다중 출력의 대칭 공분산을 서로 독립적으로 계산하면 한 ULP의 비대칭이 생겨
정확한 대칭을 요구하는 다음 모듈의 계약에 연결되지 않는 반례도 재현했다.
이제 위 삼각 부분의 쌍별 이차형을 한 번 계산하고 양쪽에 같은 값을 저장한다.
행렬 수리나 음수 자르기 없이 수학적 대칭을 보존하며 재현 반례와 25개 고정 seed
민감도 행렬로 다음 `StandardCovariance` 입력 생성까지 검사한다.
표준 불확실도는 표현할 수 있어도 그 제곱인 분산이 부동소수점 범위 아래로
떨어지는 반례도 보존했다. 출력 분산이 0인 경우에만 원 부동소수점 입력의 정확한
유리수 이차형으로 실제 영공간 상쇄인지 검사한다. 참 분산이 0이 아닌데 0으로
계산됐다면 `out_of_scope`로 거부한다. 진짜 완전 상관의 상쇄는 0으로 유지한다.
현재 API는 별도 스케일 지수나 임의 정밀도 분산을 내보내지 않는다.

```powershell
python scripts/check_metrology.py --raw-root data/raw
```

이 선택 실행은 실제 VSL 오차 요약 104건을 일차원 identity로 다시 표현해 출처의
U/k와 확대 U를 보존하는지 확인한다. 펄스계수 요약 19건에는 오차가 없으므로 건너뛴다.
기준/지시 질량 유량의 성분 공분산이 미상인 실제 회차는 전체 예산을 보류한다.
원자료 시각은 `None`으로 유지한다. 이는 공급자 스칼라 결과의 재표현이며 새로운
교정·독립 물리 검증이 아니다. 상세107기록은 배포 밖에 저장한다.

계량기의 시간 누적과 회차 대응, 히스테리시스·drift·동적 응답, 오류가 양 축에 있는
교정 적합, 산업별 허용 한계·거래 승인 절차·독립 현장 검증은 별도 후속 범위다.
따라서 전체 거래 계량 기술 항목을 완료로 집계하지 않는다.
