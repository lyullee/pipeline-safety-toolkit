# 공개 체결 토크·체결력 원자료 검토

이 검토는 실제 체결 시험의 토크·힘 곡선과 실험 조건을 확보해 기존 제작
인터페이스의 입력 근거로 연결한다. 토크를 재료 모델에 넣을 수 있다는 사실과
해당 조인트의 축력을 예측·검증했다는 주장을 구분한다. 이번 자료에는 검토된
nut factor와 유효 인장 면적이 없어 원 preload 계산은 보류한다.

## 출처·권리·확보 범위

선택 자료는 Adalto Farias·Fabrizio Leonardi·Sérgio Delijaicov의
[Dataset on force and torque for fastener clamping, v4](https://doi.org/10.17632/jffwrb4pcd.4),
Mendeley Data, 2023년 12월 15일 판이다. 공식 자료 페이지와 DataCite의
권리 메타데이터에서 CC BY 4.0을 확인했다. 기여자 표시는 공식 Mendeley
목록을 보존한다. 관련 원 자료 설명은 Ferreira 외 공동저자의
[Data in Brief 논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC10792756/),
DOI `10.1016/j.dib.2023.110022`에 있으며 이 논문도 CC BY다.

선택한 102개 파일의 합계는 1,281,783바이트다.

| 원 폴더 | 선택 자산 | 크기 |
|---|---:|---:|
| `1-raw_data_torque` | 토크 CSV 48개 | 658,376바이트 |
| `2-raw_data_force` | 힘 CSV 48개 | 618,053바이트 |
| `4-DOE_tables` | 실험 조건·요약 표 CSV 6개 | 5,354바이트 |

기존 곡선 그림 폴더는 다운로드하지 않았다. Mendeley 공개 API의 각 파일
메타데이터에 있는 크기·SHA-256을 고정해 공통 다운로더로 직접 취득했다.
별도 재료 프로젝트의 원자료를 복사하지 않았다. 저자·DOI·버전·라이선스·
공급자 체크섬은 공통 카탈로그와 공개 검토 결과에 남긴다.

공식 페이지의 루트 파일 목록은 비어 있지만 폴더 안의 파일은 존재한다.
폴더 목록은 `/public-api/datasets/jffwrb4pcd/folders/4`로, 각 파일 목록은
같은 dataset의 `/files?folder_id=FOLDER_ID&version=4`로 확인했다. 루트의
빈 목록이나 dataset 요약의 크기 0을 전체 원자료의 부재로 해석하지 않는다.
권리·파일 목록·공식 페이지와 관련 논문 캐시는
`artifacts/source_metadata/fastener_clamping/`에만 보존한다.

## 실제 파일의 의미

원 토크·힘 파일은 쉼표 구분 CSV다. 헤더는 다음과 같다.

```text
Angle (summary) [deg],Torque [Nm]
Angle (summary) [deg],Force [kN]
```

첫 열은 회전각도이며 경과 시간이 아니다. 토크는 N·m를 그대로 사용하고
힘은 원 kN 값과 N으로 변환한 값을 함께 보존한다. 변환 배율은 1,000이다.
음의 토크·힘을 절댓값으로 만들거나 0으로 자르지 않는다. 원 행 순서와 행
번호, 원 셀 문자열도 함께 남긴다. 비수치·비유한 값은 미상으로 두며 점을
삭제·평활·보간하거나 각도를 정렬하지 않는다.

48쌍의 시험 ID는 `raw_data_torque_test_01t.csv`와
`raw_data_force_test_01f.csv`처럼 원 파일 번호를 유지한다. 같은 번호라도
원 각도 벡터가 완전히 일치하는지를 별도로 검사한다. 길이와 모든 각도가
유한하고 정확히 같을 때만 같은 원 각도 위치의 힘을 함께 기록한다.
격자가 다르면 두 곡선을 따로 보존하고 대응 힘은 미상으로 둔다. 최근접 점이나
각도 보간으로 관측 쌍을 만들지 않는다. 같은 각도 좌표라는 사실만으로
독립적으로 검증된 시간 동기화를 주장하지 않는다.

현재 원 토크는 34,950행, 힘은 32,159행이다. 모든 값은 유한하지만 음의 토크
332개와 음의 힘 146개가 있다. 48쌍 전체에서 각도 벡터가 완전히 일치한
경우는 없고, 96곡선 중 29개는 각도가 엄격히 증가하지 않는다. 이를 정렬하거나
지워서 완전한 동시 이력처럼 만들지 않았다. 이번 검토의 동일 각도 선택점
대응 힘은 모두 미상이며 두 원 곡선 자체는 전부 남겼다.

DOE 표 6개는 세미콜론 구분 CSV다. `table_2.csv`는 첫 행에 `Run #`,
`Replicate`, 마찰 조건, 속도, 도장, 받침판 경도와 실험 요약의 열 이름을,
두 번째 행에 단위를 담는다. 이 두 행과 끝의 빈 메타데이터 행을 원문대로
보존한다. 비어 있지 않은 Run 행만 실험 조건의 대응에 사용한다. CSV의
`Run #`와 같은 번호의 원 파일을 연결하고 `Replicate`와 인자 조합을 함께
남긴다. 이 번호에서 실제 시험 실행 시각이나 임의의 독립 시험 순서를 추정하지 않는다.

실제 조건은 인자 조합 16개에 각 3회 반복이며 `Replicate` 1·2·3은 각각
16개 시험에 표시돼 있다. 48개 Run과 두 헤더 행, 끝의 빈 메타데이터 3행을
보존한다. 같은 조합의 반복 행과 각 곡선의 점을 별개의 물리 조건으로 세지 않는다.

관련 논문은 M10×1.50 나사·너트, zinc-flake 표면 처리, 두 명목 마찰 조건,
두 속도 수준, 너트 KTL 도장 유무와 받침판 경도를 설명한다. 이 명목 형상
근거는 지름 0.01 m와 피치 0.0015 m로 명시하지만 규격의 인장 유효 면적을
가져오지 않는다. DOE의 마찰 계수 조건은 토크식의 nut factor와 같은 값이 아니다.
받침판 경도 수준도 Vickers 압입의 원 힘·대각선 기록이나 규격 허용치가 아니다.

속도는 별도 주의가 필요하다. 원 DOE CSV에는 `[rad/s]`가 있지만 관련 논문
본문은 동일한 10/200 수준을 rpm으로 설명한다. 양쪽 표기를 보존하고 이
불일치를 미해결로 기록한다. 어느 쪽을 조용히 고르거나 각도를 속도로 나눠
시간 이력을 만들지 않는다. DOE의 P와 T 요약도 원 곡선의 동시 극값이나
교정된 모델 정답으로 대체하지 않는다.

## 기존 제작 모델에 전달한 범위

각 시험에서 유한한 원 토크 중 가장 큰 부호 있는 값을 진단용 대표점으로
명시적으로 선택한다. 동률이면 원 순서의 첫 점이다. 원 곡선 전체는 그대로
보존하며 이 선택은 체결 종료·안정 축력·검토된 토크 제어 구간을 뜻하지 않는다.
선택 각도와 대응 힘도 격자 조건이 충족될 때만 비공개 상세에 기록한다.

`fabrication_exchange.evaluate_fabrication`에는 실제 선택 토크와 논문 근거의
명목 지름을, `nut_factor`와 `tensile_area_m2`에는 `None`을 전달한다.
각 시험의 `clock_id`는 각도만 있고 경과 시간이 없다는 정적 snapshot 의미를
명시한다. 원 모델에는 시간 이력을 입력하지 않는다. 토크 구간·마찰/윤활과
유효 면적의 검토 플래그를 임의로 참으로 만들지 않는다.

모든 시험은 `needs_data`, 빈 계산값과 `native_receipt=None`으로 남긴다.
측정된 힘은 독립적인 원자료로 보존하며 모델 입력에 넣지 않는다. 그 힘에서
nut factor를 역산한 뒤 같은 힘을 재현했다며 검증 성공으로 표시하지 않는다.
원 모델의 법칙을 복제하지 않았으며 이번 보류 결과는 모델 수치 정확도나
현장 preload 예측 능력의 검증이 아니다.

## 재현·결과·후속 근거

### 재사용 Python reader

연구 스크립트에서만 접근하던 곡선 CSV 판독을 패키지 API로 분리했다.
`pipeline_integrity.fastener_data.read_fastener_trace(path, kind=None)`는 허용된
공급자 카탈로그 자산명, publisher metadata SHA-256, 파일 크기, 헤더와 행 모양을 확인한다.
트레이스 하나씩 처리하므로 48개 시험 묶음을 메모리에 올리지 않는다. 결과에는 DOI·저자·버전·
라이선스·trial 번호·원 SHA와 원 행/셀 문자열이 붙는다. 힘은 kN과 N을 구분하고 토크는 N·m로
보존한다. 결측·부호·각도 순서를 보존하며 각도를 시간으로 바꾸거나 보간하지 않는다.

```python
from pipeline_integrity.fastener_data import read_fastener_trace

trace = read_fastener_trace(
    "data/raw/fastener_clamping/raw_data_torque_test_01t.csv"
)
```

반환값은 원 측정값을 담으므로 호출자가 지정한 비공개 작업 폴더에만 저장한다. 기존
`review_fastener_source.py`도 이 API를 호출한다. 이 reader는 조임 종료 상태, bolt preload,
nut factor, 동시 힘 계측, 플랜지 누설방지 성능을 계산하지 않는다. 회귀는 작성됐으며 누리온
대기다.

저장소 루트에서 다음을 실행한다.

```powershell
python scripts/acquire_data.py --only fastener_clamping --workers 4 --maximum-seconds 60
python scripts/review_fastener_source.py --materials PATH_TO_MAT
```

원자료 위치를 바꾸면 검토 명령에 `--root PATH_TO_FASTENER_DATA`를 추가한다.
각 파일의 공급자 SHA-256·크기를 확인한 뒤 읽고 실행 후 다시 확인한다.
Mat 소스는 수정하지 않으며 실행 전후 Python 소스 트리의 해시와 파일 수를
기록한다. 모든 원·변환 행, DOE 조건·원 인덱스와 시험별 보류 receipt는
`artifacts/fastener_source/`에만 저장한다.

[공개 요약](../research/fastener_source_results.json)은 이용 조건·체크섬·자료 구조,
실험/행/음의 관측 수와 격자 대응의 집계, 단위 충돌·입력 공백과 보류 상태를
담는다. 원 수치 행이나 변환된 행을 코드 배포에 넣지 않는다. 취득 완료와
preload 계산·독립 검증·실제 조인트의 자격 확인은 별개의 상태다.

후속 정량 적용에는 체결 구간의 정의, 토크·힘의 동시 계측과 교정 불확실성,
실제 형상·유효 인장 면적, 나사/받침면·윤활·표면 처리에 맞는 별도 nut factor
근거가 필요하다. 적합을 수행한다면 같은 인자 조건과 반복 시험을 보존한
분할을 먼저 선언해야 한다. 같은 관측으로 보정한 값을 독립 평가 정답으로
재사용하지 않는다. 배관 플랜지·가스켓·압력 용량·누설 방지·현장 체결 승인으로
자동 전이하지 않는다.
