# 원래 요구사항과 현재 증거 대조

현재 구현 36·인터페이스 확인 99·외부 0·계획 0·부분 37·절차 29다. 구현+실제 연계는

정적 검사만 확인했다. 새 numerical pytest 실행은 누리온 검증 대기다.
감시의 명시된59개 원 ID는 실제 실행했으나 실제 fault truth/population 성능 검증,
일반 토양/관/유체 연성과 고급 수송·역추정·위험·최적화·현장 절차는 계속 남아 있다.

최근 위험 연결에서는 기존 HRA의 근거 바인딩·FTA·ETA·LOPA와 PRISM 요구 시

물리적인 봉쇄 상실 연계는 남아 있다. 단순 인터페이스 제공을 전체 위험
평가나 현장 검증의 완료로 집계하지 않는다.

전체 목표는 배관 기술 전반의 모듈화다. 검사가 통과한 일부 계산이나 배포
기반만으로 전체 목표 완료를 선언하지 않는다. 구현 상태는 기술 카탈로그와
실제 실행 결과를 함께 확인한다. 새 기능 추가 후 이 대조표와 상태를 갱신한다.
