# 계산 원리와 적용 범위

모든 식은 독립적으로 설명하며 계수표·설계 허용값은 포함하지 않는다. 원
라이브러리의 상세 적용 영역도 확인해야 한다. 전체 입력·출력 필드와 단위는
CLI의 `describe` 결과가 기준이다. 예제 입력은 대상 설비의 설계 권고값이 아니다.

## 수력과 기하

`geometry.pipe`는 원형 단면의 면적과 길이에서 내부·관벽 체적, 질량과 외부
면적을 계산한다. 외경이 내경보다 커야 한다.

`hydraulics.liquid_loss`는 Darcy 마찰 손실, 사용자가 선언한 국부 손실과
고도차를 결합한다. Re는 유속 크기로 계산하고 마찰 압력차에는 흐름 방향을
적용한다. 소산 동력은 흐름이 역전돼도 비음수다. 유량 0에서는 마찰을 0으로
처리하고 정수압 항은 유지한다. 전이 Re 2,300~4,000은 기본적으로 보류한다.
명시적 정책 변경 시에도 전이 영역의 정확성이 검증됐다는 뜻은 아니다.

마찰계수 기본값은 Fluids의 Clamond 해법이다. Colebrook·Haaland·Swamee-Jain을
선택할 수 있다. 이식된 폐쇄식 하나로 고정하는 대신 공개 구현의 선택과
검증을 사용한다. [Fluids 마찰 API](https://fluids.readthedocs.io/fluids.friction.html)
의 Darcy/Fanning 구분을 확인한다.

`hydraulics.hydrostatic`은 일정 밀도와 고도차를 사용한다. 계산 절대압력이
0 이하가 되면 보류한다. 증기압·공동화 여부까지 판정하지 않는다.

가스 경험식은 Weymouth·Panhandle A/B·Spitzglass high를 선택한다. 상대밀도,
평균 온도·Z·효율·기준 온도/압력을 사용자가 공급한다. 수소·극저온·2상으로
자동 확장하지 않는다. `isothermal_gas`는 평균 밀도와 Darcy 계수를 공급받는
등온 수송 해석이며 열수력 반복해석이 아니다.
[Fluids 압축성 API](https://fluids.readthedocs.io/fluids.compressible.html)

## 과도현상과 관망

`wave_speed`는 유체 압축성과 관벽 탄성을 직렬 컴플라이언스로 결합한다.
관 구속 계수와 탄성계수는 검토한 입력이다. `surge_pulse`는
`rho * a * (v_initial - v_final)`의 단순 압력파 규모와 왕복 시간 `2L/a`를
계산한다. 반사·폐쇄 이력·액주 분리·공동화를 푸는 수격 해석기는 아니다.

물 관망은 [WNTR](https://usepa.github.io/WNTR/)와 EPANET 2.2를 사용한다.
입력 관망의 손실식·수요 모델을 기록하고, 각 접점에서 유입-유출-수요의
잔차를 직접 검사한다. 압력 수두는 m로 유지한다. 가스·다상 관망은 이
어댑터 범위에 들어가지 않는다.

## 장치와 계측

| 계산 | 원리 | 주요 제약 |
|---|---|---|
| pump_power | rho·g·Q·H와 펌프·모터 효율 | 정상 액체, 공급 효율 |
| pump_affinity | 기하학적 상사에서 Q∝N·D³, H∝N²·D², P∝N³·D⁵ | 효율 일정, 임펠러 절삭 일반식 아님 |
| pump_npsh | 흡입 표면 압력·증기압·위치·손실 수지 | 공급자 NPSHr와 여유 기준 필요 |
| compression | CoolProp 등엔트로피 출구와 효율로 실제 엔탈피 증가 | 단상 가스/초임계, 단열, 맵·다단 미포함 |
| liquid_dp_meter | 개구 면적·차압·밀도·베타비·선언 Cd | 비압축성, 단상, 교정·캐비테이션 검토 별도 |
| control_valve_liquid/gas | Fluids의 크기 산정 호출 | 제조사 FL·Fd·xT 및 설치 조건 필요 |
| relief_gas | Fluids 기체 방출 면적 상관식 | 방출 시나리오·인증·완전한 규격 적합성 별도 |

밸브의 Kv는 관례적인 m³/h 계수이며 SI 유량 자체가 아니다. 가스 제어밸브의
입력 기준 체적은 이 어댑터에서 273.15 K·101325 Pa로 고정한다. 다른 기준
체적은 먼저 물성·기준을 명시한 변환이 필요하다. 제조사 계수는 숨은 기본값으로
채우지 않는다. [제어밸브 API](https://fluids.readthedocs.io/fluids.control_valve.html),
[방출장치 API](https://fluids.readthedocs.io/fluids.safety_valve.html)

## 열역학·열전달·재고

물성은 기본적으로 [CoolProp](https://coolprop.org/coolprop/HighLevelAPI.html)을
호출한다. 정확한 상태쌍과 상을 먼저 결정하며 지원하지 않는 수송 물성을 0으로
대체하지 않는다. `inventory.uniform`는 실제 상태 밀도와 체적에서 질량을
얻고 같은 질량을 명시한 기준 상태의 체적으로 환산한다. 공간적으로 변하는
상태는 `inventory.segmented`로 각각 물성을 평가해 질량·내부에너지를 적분한다.
상태의 공간 분포를 생성하는 수송 해석은 별도 엔진이 맡는다.

`flow_cooling`은 일정한 유량·열용량·총 열전도도에서 주변 온도로 지수적으로
접근하는 정상 해다. 상변화·토양 과도는 없다. `free_expansion`은 구속 없는
선형 열팽창이다. 지지 반력·열응력은 기존 구조 엔진이 맡는다.

내부 대류는 [ht](https://ht.readthedocs.io/ht.conv_internal.html)의 상관식을
선택한다. Gnielinski에는 Re·Pr 범위를 추가 검사하고 전이는 보류한다.
열 입구 길이·벽 조건·물성 변화는 별도 검토한다. 다층 원통 열전달은 기존
`matintegrity`를 호출해 복제하지 않는다.

## 사고 이력의 물리 계약 점검

사고 방출 계산은 기존 소유 엔진이 수행한다. 이쪽에서는 좌측 유지 이력의
각 구간에 대해 `Σ(mdot_i * Δt_i)`와 `Σ(mdot_i * h_i * Δt_i)`를 재계산해
공급한 질량·정적 엔탈피 누계와 비교한다. 단일 유한 제어체적의 질량은
`m_final + m_out - m_initial`로 검사한다. 잔류 질량이 양수여도 이를 고갈로
바꾸지 않는다. 내부에너지·벽 에너지·열 원장이 없으면 전체 에너지 보존을
입증한 것으로 표시하지 않는다.

2상에서 방출 후 혼합물 밀도와 분리 기체 밀도는 다르다. 공급한 주변 압력과
혼합 엔탈피가 2상 상태를 나타내면 기체 분기를 같은 물성 공급자의 포화 증기
상태와 비교한다. 이는 동일 EOS의 내부 일관성 검사이며 독립 실험 검증이 아니다.
일치하지 않는 밀도·온도·유체명·좌표를 래퍼에서 바꿔 맞추지 않고 보류한다.

## 경제·시공·절차

`cashflow`의 첫 항은 시점 0이다. 균일 기간 할인율과 통화·가격 기준 연도를
선언한다. 자동 환율·물가 보정은 없다. `energy`는 운전 동력·시간에서 kWh를
얻고 선언 요금·배출계수를 적용한다. 수명주기 분석으로 확대하지 않는다.

굴착량은 선언한 사다리꼴 단면과 팽창 비율의 기하 계산이다. 지반 안정성,
인양 허용하중, 용접 자격, 시험 승인, 수리 선정 등은 현장 절차·공급자·규격의
검토가 필요하다. 절차 API는 기록과 필수 근거를 점검하며 공법의 안전성을
자동 판정하는 계산기로 표시하지 않는다.

## 유한 구동 액체 밸브의 경계식

기존 장치의 개도 이력을 사용자가 제공한 CdA 곡선으로 변환하고 액체 MOC의
접점 연속식과 동시에 푼다. 손실식은 ΔH=q|q|/(2g(CdA)²)이며 H는 위치와
게이지압으로 구성한 피에조미터 수두다. 역류 부호·닫힘 CdA·병렬 경계를
보존한다. 최소제곱 종료 상태 외에 SI 단위 접점 유량·밸브 수두 잔차를
독립 판정하고 실패한 단계는 accepted history에 추가하지 않는다.

전체 및 관별 선형 저장량 수지를 대조한다. q·ΔH로 계산한 소산 동력은 이
준정상 밸브식의 지표이며 완전한 열역학 에너지 검증이 아니다. 수식·조건·
수치 허용오차·기준 문제와 한계는 [밸브 문서](VALVE_TRANSIENT_KO.md)에 있다.

## 압력 이력 피로의 소유 경계

공정 이력→원주 막응력→레인플로→선언 수명 곡선→단순 손상 합은 별도
재료 엔진을 사용한다. 이쪽에는 그 계산을 복제하지 않고 압력·온도·기원·
자료 창·곡선 영역의 전달과 원 수치 장부 대조를 둔다. 압력파의 H는 고도를
뺀 뒤 절대압으로 바꾸며 열해석 없이 벽 온도를 계산했다고 표시하지 않는다.
공개 신호에 가상 형상을 붙인 조건부 계산과 독립 재료 시험은 구분한다.
수식·반주기·한계·실제 재현은 [피로 문서](PRESSURE_FATIGUE_KO.md)에 있다.

## 구간 분할 정상 기체 관망

기존 접점의 질량·P/h 혼합과 입구 밀도 기반 Darcy 관을 연결한다. 관의
길이·열·국부 손실을 합이 유지되게 나누고 물성 변화·마하수를 각 구간의
실제 도착 상태에서 검사한다. 기준 엔탈피를 뺀 독립 에너지 잔차와 별도
질량 수지를 대조한다. 정체 노드의 미결정 엔탈피는 해로 승인하지 않는다.
정적 엔탈피 이송을 전체 운동/위치 에너지로 확대하지 않는다. 수치 기준·
식·물성·실험과의 구분·GasLib의 미해결 매핑은 GAS_NETWORK를 따른다.

## 자원 일정의 수학과 의미

유한 정수 격자에서 각 필수 작업의 모드 하나와 비선점 interval을 선택한다.
원 CP-SAT의 누적 용량·시간 관계를 쓰고, 반환 일정은 별도 시작/끝/달력
사건 순회와 소모품 합·기간·관계·목적 재계산으로 대조한다. 같은 시각의
자원 변경을 합쳐 half-open 구간 의미를 유지한다. 정수 하한과 목적의 일치가
없는 원 OPTIMAL은 정확 최적으로 표시하지 않는다. 선언한 비용·계획의
해일 뿐 실제 승인·실행·위험 최소화는 아니다. SCHEDULING에 세부 식과 사례가 있다.

## 반응 시간·복구의 모델 선택

원 HRA의 파라미터 시간 모델과 KM의 우측 중단 처리를 먼저 재사용했다.
모든 시간을 완료 시각으로 간주하는 방법 대신 중단과 오반응을 명시해 계산
지원 범위를 정했다. cognitive_chain은 앞 단계 성공 조건의 분해이고 공인
정량 방법 전체를 구현했다는 뜻이 아니다. 비교한 PNNL 2024 연구 소개와
확률적인 사용 가능 시간의 후속 판단은 HUMAN_RESPONSE_KO를 따른다.

## 유한 검사 계획의 선택 기준

기존 Mat의 POD/무지시 조건부 갱신과 공유 OR-Tools 일정을 우선 재사용했다.
확률 신뢰도, 시간·자원과 무조건 미발견 기준을 분리했다. 지원 범위 밖을 외삽하거나
반복 검사에 독립을 자동 적용하지 않는다. NASA NTRS의 2022년 검사 연구 설계 소개는
다른 산업 분야의 자격을 그대로 이전할 근거가 아니다. Google의 정수 최적화 설명을
확인해 점수 올림과 오차 범위를 명시했다. 링크와 채택/보류는 INSPECTION_PLANNING_KO
및 research/inspection_planning_methods.json에 기록했다.

## NDE 자료·추가 추정법 검토

공급자 MIT 메타데이터와 MD5를 고정한 TUBERS 자료를 확보했다. 조건부 두께 계산은
원 Mat을 재사용하고, 자료에 없는 교정·독립 trial·에코 의미를 만들어 넣지 않았다.
AFRL의 POD Pro 4.5는 독립 비교 후보로만 조사했다. 알려진 정답/군집/절차와
독립 검증 없이 기존 미확정 추정을 수렴한 숫자로 교체하지 않는다. 기록과 링크는
research/nde_methods.json 및 NDE_DATA를 따른다.
