# ZIP 경로 계층 충돌 검사

`datasets.inspect_zip`은 개별 멤버 경로 검사와 함께 파일-부모 충돌도 거부한다. 예를 들어 `node`가 일반 파일인 ZIP에는 `node/sensor.csv`를 둘 수 없다. 이 검사는 항목이 ZIP 안에 입력된 순서와 대소문자 표기가 달라도 적용한다. 명시 디렉터리와 그 하위 멤버는 허용한다.

검사는 archive를 추출하지 않고 수행하며, 공급 payload의 CRC를 다시 계산하지 않는다. 허용되지 않은 항목 하나라도 있으면 inventory 전체를 실패시킨다. 압축 해제 크기/비율 한도나 공급자 체크섬 검증을 대신하지 않는다.

이 경계 회귀는 합성 ZIP만 대상으로 작성했으며 실행은 누리온에서 대기한다.
