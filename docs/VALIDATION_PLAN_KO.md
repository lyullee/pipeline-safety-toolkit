# 새 구현의 누리온 검증 계획

이 문서는 실행 계획이며 통과 기록이 아니다. 현재 연구 전체의 확정 진행률과
별도로 `research/validation_queue.json`의 새 구현을 검증한다. 이전 전체2,403개와
유보 전 압력파33개 결과를 새로운 소스/엔진의 통과 수로 재사용하지 않는다.

## 공통 실행과 수락

동결 소스 계획·원 의존성·자료 체크섬을 고정하고 MPI shard별 실제 JUnit과
receipt를 남긴다. 누락·취소·환경 차이·오류·실패·기본정책의 생략은 전체 통과가 아니다.
모든 시험 모듈의 실제 사례가 집계되어야 한다. 단일 함수나 합성 예제가 통과해도
전체 기능이나 현장 자격이 완료됐다고 표시하지 않는다.

Ruff/컴파일·AST 목록·소스/패키지 검사·원자료 디코딩은 수치 검증과 구분한다.
배포 소스에 넣지 않은 원자료/원소유 엔진은 별도 staging하고 원 고지를 유지한다.
조건이 부족해 needs_data/out_of_scope로 반환하는 사례도 의미 있는 계약 검증이다.
다만 실제 native 정상 경로 없이 보류 시험만 통과한 모듈은 엔진 연동 확인으로 승격하지 않는다.

각 모듈의 구체 허용오차는 원 요청에 선언하고, 오차가 컸다는 이유만으로 실행 후
한계를 넓혀 통과 처리하지 않는다. 수정 시 원 실패와 수정한 소스/근거를 모두 남긴다.
HPC 병렬 실행은 독립 물리 사례를 늘리지 않는다. 수치 수렴·분할 일관성과 실험 비교는
회귀 사례 수와 별도의 근거로 기록한다.

## 확보 자료를 적용할 때

관 마찰의 여섯 운전점은 하나의 pilot 장치 자료다. 온도 유래 점도를 독립 점도계
측정으로 바꾸지 않고, 동일 자료에서 적합한 roughness/minor-loss를 독립 정답으로 쓰지 않는다.
실제 직관과 부차손실·단위·pressure head 기준을 확인한 원 모델 적용이 다음 단계다.

음향500/386 clip은 독립886개 실험이 아니다. 물리 사건·장치·위치 grouping과
진폭/시계 근거가 생기기 전에는 학습/검증 무작위 분할로 현장 성능을 주장하지 않는다.
718MB 압력파 자료도 공급자 checksum과 목록 확인만 완료됐으며 선택 CSV의
단위/시계/동시성은 따로 확인해야 한다. 느린 압축 접근의 timeout은 물리 모델 실패가 아니다.

기존 LN2·NASA·용접·구리·배관 자료는 각 원자료 매뉴얼의 조건과 모델의 적용 범위를
대조한다. 유체·장치·상·경계가 다른 자료를 새 엔진의 독립 검증으로 자동 전용하지 않는다.

## 결과 승격

실제 실행한 JUnit·solver/budget 기록·환경·source checksum·독립 비교를 검토한 뒤
capability별 좁은 완료 조건을 충족한 경우에만 상태를 바꾼다. 부분 기능의 한계를
삭제하거나 전체 범위를 축소해 수치상 진행률을 올리지 않는다. 원 엔진 확장이 남으면
그 요청을 별도 세션에 전달하고 현재 카탈로그에는 미완료로 남긴다.
## 공동 잔차 및 전송 확인의 추가 대기 항목

운전점 공동 잔차 행렬은 기본 단일 채널 척도와 별도 사례로 검증한다. 단위가
다른 두 채널의 선형 forward에 대해 독립적으로 유도한 일반화 최소제곱 기준과
대조하고, 행 순서 변경 시 같은 물리 결과가 유지되는지 확인한다. 상관 행렬을
단위 없는 precision으로 잘못 취급하거나 기존 scalar 척도를 한 번 더 나누지
않는지 포함한다. 기존 시간 API와 행렬 미공급 운전점 API의 결과도 비교한다.

훈련·heldout·masked·unused 행을 분리해 훈련 principal block만 최적화에 쓰는지,
heldout은 자체 marginal block으로만 평가하는지 확인한다. 미상 원소·불완전
행렬·비대칭·비양정치·중복 행 ID·단위 불일치·예산 초과·미검토 근거·provider 변경을
각각 다룬다. cross-split 상관이 미상 또는 0이 아닌 상황을 독립 검증으로 표시하지
않는지 확인한다. 부분 행렬의 계산 가능성이 전체 오차 모형의 타당성을 뜻하지
않으며, deterministic weighting으로 신뢰구간이나 사후확률을 만들지 않는다.

원자료 전송 도구는 작은 임시 파일로 누락·같은 크기의 다른 바이트·크기 불일치·
경로 이탈·대소문자 충돌·중복 JSON·비유한 값·hard link·기존 output을 검사한다.
실제 원자료의 해시 일치는 물리·통계 시험 수와 별도로 보고한다. Windows에서
확인한 경로/descriptor ctime 차이와 Linux에서의 읽기 전후 식별자 비교도 검증한다.
전송 확인만으로 시험 fixture 경로 준비나 자료 이용 권한을 승인하지 않는다.
