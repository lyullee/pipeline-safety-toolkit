# 지반 변위와 선형 관 프레임의 연결

`soil_pipe.py`는 공급한 지반 절점 변위와 양방향 선형 지지강성을 기존 관 프레임 계산기에 연결한다. 지반의 연속체 해석기나 새로운 beam/FEM solver를 만들지 않는다. 직선 부재로 구성한 원형 중공 관, 검토된 탄성 물성, 자중·내용물·부력의 정적 단일 사례를 대상으로 한다. `structural.soil_pipe` 전체 기술은 부분 구현이며 지반 항복, 지지 인장분리, gap, 마찰, 좌굴, 소성 및 동역학은 해결하지 않는다.

## 기존 소유 계산기

`structural.py`의 `annular_frame_section`, `FrameRequest`, `solve_frame`을 사용한다. native solver는 기존 어댑터가 검토한 PyNiteFEA 3.2.0이며 이 모듈이 버전을 변경하지 않는다. 기존 프레임은 독립 전역 힘/모멘트 및 절점 member-end 수지 검사를 수행한다. 지반 변위 변환 후의 물리 수지는 공개 `audit_frame_equilibrium`을 한 번 호출하여 동일 소유 계산을 재사용한다. `physical_equilibrium_audit_record`에는 versioned 공개 감사 영수증과 요청/반력/부재 결과 digest, 문맥·단위·소스 지문을 보존한다. 사설 helper를 import하거나 감사식을 복제하지 않는다.

기존 `soil_fem.py`와 `pipe_soil_transient.py`는 열전달 기능이다. 그 토양 온도 계산 결과를 기계 지반변위나 강성으로 해석하지 않는다. 탄성 E/Poisson 비와 추가 재료 검토는 기존 재료 소유 모듈 또는 근거 있는 공급 물성에서 가져온다. 이 모듈에 강재/토질 규격값을 내장하지 않는다.

## 입력 API

`SoilPipeRequest`는 형상·재료·단면·앵커가 정의된 무하중 `FrameRequest`, 지반 절점 지지, 모든 부재의 체적력 상태, 좌표/포트/지반 사건 및 검토 플래그를 받는다. 기존 프레임 검토 플래그도 참이어야 native 계산이 가능하다. `examples/soil_pipe.py`의 `make_case()`는 기본값에서 `needs_data`이며 가상 입력이다.

관 프레임은 하나의 하중 사례와 계수 1의 조합 하나를 가진다. 기존 node/line load와 initial strain을 넣을 수 없다. 압력·열팽창·일반 외력을 추가한 복합 사례는 후속 소유 확장 범위이다. 앵커의 고정/부과 변위는 기존 프레임 계약대로 공급할 수 있다. 지반 spring은 별도 계약에서만 선언하며 앵커 고정 DOF와 같은 축에 놓을 수 없다.

`SoilNodeSupport`는 절점별 global DX/DY/DZ 축의 양의 강성 N/m과 동일 기준점에서 측정한 지반 변위 m를 받는다. 이는 이미 이산화된 절점 강성이다. 지반 반력계수 N/m³나 단위 길이 지지강성 N/m²를 자동 변환하지 않는다. tributary 길이·접촉폭·지층 조건과 mesh 적용성은 공급자가 검토한다. 축별 독립 양방향 spring이며 축 간/절점 간 강성 결합은 지원하지 않는다. null은 미상이고 없는 축은 모델에 없는 지지이다.

behavior 기본값은 unreviewed이다. bilateral은 인장/압축 양쪽을 전달하는 검토된 선형 연결이라는 뜻이다. 실제 토양이 인장력을 전달한다는 자동 가정이 아니다. compression_only 또는 gap을 요청하면 native 호출 전에 `out_of_scope`로 반환한다. 실제 지지가 분리될 수 있는데 편의를 위해 bilateral로 바꾸지 않는다.

`SoilPipeBodyState`는 부재별 외경/내경 m, 관과 부착물 질량 kg/m, 내용물 질량 kg/m, 유효 배제 면적 m², 침수 비율 및 외부 유체 밀도 kg/m³를 받는다. 기존 `annular_frame_section`으로 계산한 A/I/J와 프레임 단면이 일치해야 한다. 배제 면적은 단열재나 외피 등을 반영할 수 있어 관 외경으로 추측하지 않는다. 질량/부력 값이 미상이면 0으로 대체하지 않는다.

모든 위치·지반/관 변위·중력 벡터·힘은 선언한 동일 Cartesian 좌표계에 놓인다. 회전은 rad, 하중은 N 또는 N/m, 모멘트는 N·m, E는 Pa이다. 지반 사건은 단일 시계/시점의 snapshot이며 좌표계·양단 포트·지반 사건·전체 요청 digest가 `RunContext`에 결합된다. 부재 중간의 형상 절점은 기존 프레임 규칙대로 명시 분할한다.

## 변위 전달과 부호

공급 지반 변위를 `u_g`, 관 절점 변위를 `u_p`, 이산 강성을 `k`라고 한다. 물리적인 지반의 관에 대한 힘은 `R = -k*(u_p-u_g)`이다. 관이 지반에 주는 힘은 정확히 반대 부호로 보고한다.

기존 선형 프레임은 spring의 기준 변위를 0으로 두므로 `k*u_g`의 등가 절점 힘을 추가한다. native spring 반력 `R0=-k*u_p`는 물리적인 지반 힘이 아니다. 결과에서 `R0+k*u_g`로 변환하고, 별도로 계산한 `-k*(u_p-u_g)`와 대조한다. native 값과 변환 값, 상대 변위를 모두 남긴다. 전역/절점 물리 감사에서는 가상의 `k*u_g` 외력을 제거하고 실제 지반 힘으로 대체한다. 등가 절점 힘을 실제 외력과 실제 지반 반력에 동시에 더해 이중 계상하지 않는다.

이 변환은 기준점 이동이 있는 선형 양방향 spring의 정적 대수 변환이다. 이동 지반에 대한 비선형 접촉 활성 집합이나 인장분리 알고리즘이 아니다. 관 처짐을 지반 변위와 같게 강제하는 것도 아니다.

## 체적력과 수지

부재별 유효 질량 선밀도는 `m_eff = m_pipe_attached + m_contents - immersed_fraction*rho_external*displaced_area`이다. 전역 등분포 하중은 `m_eff*gravity`이다. 부력 우세인 음의 유효 질량을 보존하며 0으로 잘라내지 않는다. 원 질량, 배제 유체 질량 및 실제 signed 선하중을 장부로 반환한다. 체적력은 공급한 균일 상태를 부재 전체에 적용하며 유체의 추가 질량·항력·압력 변형은 포함하지 않는다.

기존 프레임의 수지뿐 아니라 변환 후 물리 전역 힘/모멘트 수지, 절점 member-end 수지와 spring-law 일치를 모두 요구한다. 모멘트 기준점과 절대/상대 수치 허용오차는 기존 프레임 요청을 유지한다. 해석 불안정, 큰 변위/회전 범위 이탈 또는 수지 실패는 `out_of_scope`이며 실패 원인과 소유 결과를 보존한다. 선언한 static snapshot은 시간 적분된 운동 에너지나 지반의 일 이력을 계산하지 않는다.

## 휨 출력의 의미

관 부재별 native local 축 변환 행렬과 sample 위치, My/Mz 및 My/(EIy), Mz/(EIz)를 제공한다. 모멘트 부호는 기존 PyNite local member convention을 유지한다. M/EI는 공급한 선형 탄성 강성으로 정규화한 지표이며 별도의 소성 곡률 모델이 아니다. 표본 위치의 모멘트 합성값 최대를 반환하지만 전 부재의 연속 최대값이나 보수적 상한으로 표시하지 않는다. 단면 타원화, 주름, 국부/전체 좌굴, 용접부 및 허용 응력/변형률 판정은 하지 않는다.

`computed_diagnostic`은 현재 검토된 선형 사례에서 native/물리 수지가 통과했다는 계산 상태이다. 지반 강도나 관 강도 적합 판정, 시공 승인 또는 현장 검증 완료라는 뜻이 아니다.

## 근거·재생·현재 검증 상태

`evaluate_soil_pipe(request, context)`는 전체 요청/문맥, 체적력 장부, 실제 구성한 프레임 요청, 소유 프레임 결과, 물리 반력과 수지 및 소스/런타임 지문을 보존한다. native PyNite 소스 지문은 기존 프레임 기록에서 유지한다. `verify_soil_pipe_record(record, request=..., context=...)`는 현재 소스와 native solver로 재계산하여 전체 기록을 대조한다. 무서명 digest와 재계산은 과거 실행자의 신원이나 과거 실행 사실을 인증하지 않는다.

코드·예제·회귀 시험을 작성했고 Ruff 및 Python 컴파일을 통과했다. 사용자 지시에 따라 pytest, PyNite 또는 수치 예제를 실행하지 않았다. 실제 solver 재현·회귀 통과·mesh 수렴·현장 검증은 미완료이다. 후속 누리온 환경에서 `python -m pytest tests/test_soil_pipe.py -q`를 실행한다. 시험은 양/음 지반변위의 cantilever+tip spring 독립 해, native 반력과 실제 반력의 구분, 물리 수지, 부력 방향 반전, 미상 값과 인장분리 거부, 단면/좌표 계약 및 재봉인 변조 검출을 포함한다.

## 소유 확장 요청: PI-X05/01

구조 소유 모듈에 지반 기준 변위를 갖는 compression-only/gap spring, 접촉 활성 집합의 수렴/보완조건 및 물리 반력 영수증을 요청한다. 자체 active-set 또는 beam solver를 별도로 만들지 않는다. 전역/절점 감사의 공개 API는 현재 연결했으며 수치 재검증은 대기 중이다. 공간 결합 지지강성, 지반 p-y/t-z/q-z 등 검토된 비선형 구성식과 하중 이력을 보존하는 연결은 여전히 필요하다. 지반 소유 모듈에는 기계 변위·반력계수의 좌표/시계/지층/유효응력/적용 범위 및 mesh tributary 근거를 가진 공급 계약을 요청한다. 재료/구조 소유 모듈에는 압력·열 초기변형과 휨의 결합, 비선형 관 단면/좌굴 및 규격/제조사 검토 입력을 요청한다. 이 기능들이 없을 때 현재 bilateral snapshot을 분리 가능한 실제 매설관 지반 해석으로 재명명하지 않는다.
